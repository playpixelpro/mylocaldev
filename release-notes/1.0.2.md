# MyLocalDev 1.0.2

## Highlights

- Add installed runtime and development-tool directories directly to the Windows PATH.
- Refresh PATH entries when PHP, Node.js, Python, or the active database version changes.
- Add Python default-version selection to Terminal Commands settings.
- Remove stale MyLocalDev-managed PATH entries when versions change or terminal commands are disabled.
- Broadcast Windows environment changes so newly opened terminals can discover updated binaries.
