# MyLocalDev 1.0.1

## Fixed — projects with an existing `.env` were treated as unconfigured

- **Import reads the project's environment file.** Adding an existing project now keeps
  `DB_DATABASE`, `APP_KEY`, `APP_ENV` and every other value already in `.env` instead of
  generating defaults from the folder name.
- **Only real overrides reach the process environment.** Child processes (PHP-CGI,
  terminals, supervisor workers) now receive a value only when it is a genuine override:
  empty values are skipped, and values identical to `.env` are no longer injected.
- **Overrides are visible.** The Environment tab marks each stored value that takes
  precedence over the file, so a silent mismatch is easy to spot.
- **`$_ENV` receives injected values.** Bundled PHP — and existing PHP installations on
  first start — now runs with `variables_order = "EGPCS"`, so applications that read
  `$_ENV` see the values the app provides.

No other changes are part of this release.
